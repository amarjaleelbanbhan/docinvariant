# Contributing

Thank you for helping develop DocInvariant. This project values small, reproducible changes and clear reports.

1. Open an issue describing the bug or proposed capability; include minimal, fictional, non-sensitive examples.
2. Keep pull requests focused, and explain how every new check handles both dangerous changes and safe paraphrases.
3. Add regression tests; run `python -m unittest discover -s tests -v` locally.
4. Distinguish deterministic tool output from manual or model-based judgments. Never claim a checker can prove semantic equivalence.
5. Do not commit third-party ASD-STE100 PDF pages, dictionary entries, copyrighted examples, proprietary documentation, keys, or personal account details.
6. Do not add AI co-author trailers or attribution in commits on behalf of a contributor without their request.
7. Include what was tested, what remains unknown, and the risk of false positives or false negatives.

All contributions must be lawfully provided under the repository's open-source license. Do not submit content if you lack the rights to license it.
